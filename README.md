# Transport Cost Comparator

An Android application developed in Java and XML that calculates daily and monthly commuting expenses, tracks travel metrics using an SQLite database, and provides cost-saving recommendations for commuters.

## Features
* **Interactive Inputs:** Calculates daily & monthly expenses using trip distance, cost per kilometer, and travel frequency.
* **Date Selection:** Utilizes Android DatePicker to log travel dates accurately.
* **Local Storage:** Stores trip history locally on the device using an SQLite database.
* **Recommendations:** Evaluates monthly spend categories (Low, Moderate, High, Excessive) and offers practical commuting suggestions.
* **Audio Integration:** Includes an embedded audio player for transport announcements and speeches.

## Tech Stack
* **Language:** Java
* **UI Design:** XML
* **Database:** SQLite
* **IDE:** Android Studio
